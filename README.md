# メジェド神は守ってる

メジェド神を動かし、古代エジプトの冥界で死者たちの行進を守る3Dアクションゲームです。40ウェーブ目の大蛇アペプを倒すとクリアです。死者の被害が30人に達するか、メジェドの体力が0になると敗北します。同じブラウザで初めてゲームを開始した1回は、死者の被害が40人に達すると敗北します。

[ゲームを遊ぶ（GitHub Pages）](https://chameleonjp-lab.github.io/medjedshin_ha_mamotteru/)

## 遊び方

ホーム画面の左上にある「language」から15言語を選べます。初回はブラウザの優先順位に沿って、対応する最初の言語で表示します。対応する言語が見つからない場合は日本語で表示します。手動で選んだ言語は、同じブラウザで次回も優先されます。

スマートフォンでは、戦場の画面に触れてそのまま指を動かすと移動できます。パソコンでは戦場でマウスを動かして移動し、Sキーまたは画面の「停止」で一時停止メニューを開きます。Escキーでも開閉できます。

プレイ中は「停止」の隣の倍速ボタンで、1倍・1.5倍・2倍を順に切り替えられます。ホームの設定や一時停止メニューからも速度を選べます。選んだ速度は同じブラウザで次回も使われます。同じ場所で、画面の揺れを「通常」「弱め」「なし」から選べます。端末で「視差効果を減らす」などの動きを減らす設定をしている場合は、最初は「弱め」になります。

通常ウェーブの敵をすべて倒すと、右上の「次のウェーブへ」で時間切れを待たずに進めます。

攻撃は自動で発動します。敵が落とす経験値を集めると、全8種類のスキルから選んで取得・強化できます。画面のカードを押すか、パソコンなら 1〜3 キーで選びます。ハイスコア・最高到達ウェーブ・ベストランクは、遊んだブラウザに保存されます。

ゲームを開始すると、名前の有無にかかわらず1回として数えます。名前を入れて開始したプレイは、クリアまたはゲームオーバーでスコアを送ります。同じブラウザからの記録は自己ベストを表示し、同点は同順位です。通信できない間の開始・終了データはブラウザに保留し、再接続や次回の起動時に送ります。

[実験場の詳細ランキング](https://chameleonjp-lab.github.io/chameleonjp_lab/ranking.html?game=medjedshin_ha_mamotteru)

## v1.2の変更点

- ボスが大技をためている間に一定のダメージを与えると、発動を止められます。第10・20・30ウェーブのボスを倒すと、スキルレベルの上限を1段階上げるか、現在の上限内で好きなスキルを1レベル強化できます。
- ファラオの棺をゴールまで守り、残りHPが50以上なら黄金宝箱を獲得します。最もレベルが低いスキルを、スロットの出目に応じて1〜3レベル強化します。棺は決まったウェーブで出現するほか、通常の行進に加わる死者の抽選でも1.8%の確率で現れます。
- 全スキルがレベル10に達したあとは、強化報酬を受け取ると5秒間、攻撃力が20%上がります。

## 画質と動作確認

パソコンでは、ホームの「設定」またはプレイ中の「一時停止・設定」で、描画品質を「高精細」と「軽量」から選べます。初期設定は「高精細」です。変更はその場で反映し、同じブラウザで次回も使います。

スマートフォンでは軽量描画で起動します。高精細モデルを読み込めない場合も、軽量描画で起動します。

ゲームのURLに `?graphics=high` を付けると、スマートフォンでも同じモデルと演出を試せます。`?graphics=light` を付けると、どの端末でも軽量描画で開けます。URLの指定がある場合は、開いたときにその画質を使います。

## 動作確認と公開

ビルドは不要です。ローカルで確認する場合は、リポジトリのルートで `python3 -m http.server 8000` を実行し、ブラウザで `http://localhost:8000/` を開きます。プレイには、ブラウザで3Dを描画する機能（WebGL）が必要です。

初回はリポジトリの **Settings → Pages → Build and deployment → Source** で **GitHub Actions** を選びます。設定後、PRを `main` にマージすると自動で公開されます。手動で再公開する場合は、**Actions → Deploy game to GitHub Pages → Run workflow** から `main` を選びます。
