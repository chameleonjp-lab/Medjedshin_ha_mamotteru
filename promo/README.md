# SNS用ゲーム広告PV

`medjed_pv.mp4` は、SNSに投稿するための25秒の縦長動画です（1080×1920、30コマ/秒、H.264＋AAC）。映像も音も、実際のゲーム画面とゲームが鳴らす音楽・効果音からできています。`medjed_pv_poster.jpg` は、冒頭の「強すぎる。」の場面から取った1コマで、投稿のサムネイルに使えます。

## 動画の流れ

動画は、終盤の大混戦に「この白い神さま、強すぎる。」と文字を重ねるところから始まります。最初の3秒で手を止めてもらうための場面です。次にタイトル画面のメジェドを大きく映して主人公を紹介し、「指でなぞって動くだけ」「攻撃はぜんぶ自動！」と、操作がやさしいことを見せます。

9秒目からは、スキルを育てきったときの「神格覚醒」、後半の大群を一掃する場面と、だんだん派手になるように並べています。15秒目からは3体のボスの登場画面を約1秒ずつ切り替え、最後のボス「大蛇アペプ」との戦いと、倒して死者たちと喜ぶメジェドへとつなぎます。最後の約4秒は、タイトルと「今すぐ遊ぶ」「ブラウザですぐ遊べる・インストール不要」を出す締めの画面です。

下の帯の文字は、上下2行で15〜20字ほどあります。どれも約3秒表示して、読み終える前に次の場面へ移らないようにしています。

音は、場面に合わせてゲーム本体の音楽を切り替えています。戦いの場面はボス戦や終盤の曲、タイトルの場面は静かな曲です。レベルアップ、覚醒、ボス警告、ボス撃破の効果音も、画面の出来事と同じ時刻に鳴らしています。

## 撮影について

見せ場を短い時間で撮るため、録画のときだけ、スキルのレベルや始めるウェーブを直接設定し、メジェドの体力が減らないようにしています。メジェドの移動は、敵の多いところへ向かう簡単な自動操縦です。画面に映っているものは、どれもゲームが実際に描いた絵です。

録画には、本物のゲームファイルを変えずに作る「録画用コピー」を使います。このコピーではランキング機能を切り、さらにブラウザからの外部通信をすべて止めているので、撮影でプレー回数が増えたり、スコアが送られたりすることはありません。

## 作り直す手順

`tools/` の中に、録画・録音・合成の道具が入っています。Node.js と Playwright（ブラウザを自動で動かす道具）、ffmpeg（動画を書き出す道具）が必要です。作業は `promo/tools` の中で行います。

1. `python3 make-capture-site.py` で録画用コピーを `site/` に作り、`site/` の中で `python3 -m http.server 8765` を動かします。
2. `node record.js <場面名>` で場面ごとに映像を撮ります。場面名は `hook` `title` `early` `levelup` `awaken` `horde` `boss_ammit` `boss_set` `boss_sphinx` `victory` です。コマは `frames/<場面名>/` に保存されます。
3. `pv.json` の `audio` の部分を `tl.json` として保存し、`node audio.js tl.json pv_audio.webm` で音を録ります。
4. `promo/tools` で `python3 -m http.server 8766` を動かし、`node render.js pv.json` で文字入りの縦長のコマを `out/` に合成します。
5. 最後に ffmpeg で音の大きさをそろえ、映像と音を1本の動画にまとめます。

```sh
ffmpeg -i pv_audio.webm -af "atrim=0:25.0,acompressor=threshold=-24dB:ratio=3:attack=5:release=120,aecho=0.85:0.5:70|140:0.18|0.1,loudnorm=I=-14:TP=-1.5:LRA=9,afade=t=out:st=24.2:d=0.8" -c:a aac -b:a 192k pv_audio.m4a
ffmpeg -framerate 30 -i out/o%04d.jpg -i pv_audio.m4a -c:v libx264 -preset slow -crf 18 -pix_fmt yuv420p -movflags +faststart -c:a copy -shortest medjed_pv.mp4
```

文字の内容や表示の時刻、どの場面を何秒使うかは、すべて `pv.json` で変えられます。文字の見た目は `tools/comp/index.html` で変えられます。
